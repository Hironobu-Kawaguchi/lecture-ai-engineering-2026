## 宿題

- 取り組んだレベル：基礎
- 変えた設定やデータ：`num_train_epochs` を 20 → 10 に変更（他の設定は同じ。`lr` 2e-4、`lora_r` 16）。ベースラインは元の設定を同じ Colab 環境で再実行した。
- 結果（比較表や数字）：

| 項目 | ベースライン（20 エポック） | 変更版（10 エポック） |
|---|---|---|
| 学習前 `format_rate` / `content_rate` | 0.095 / 0.0 | 0.095 / 0.0 |
| 学習後 `format_rate` | 1.0 | 1.0 |
| 学習後 `content_rate` | 0.905（19/21） | 0.857（18/21） |
| 退行 | なし | なし |
| 最終 loss（ログの最後の値） | 0.0141（step 40） | 0.0998（step 20） |
| 平均 train_loss | 0.4215 | 0.8328 |
| 学習時間（`trainer.train` の時間） | 229 秒 | 116 秒 |
| 学習後の評価時間 | 41.0 秒 | 41.5 秒 |

- 変更版で増えた失敗（3件）：
  - 根拠ありの「PDF 以外でも出せますか」を `needs_review: true` と判定（確認要求で逃げた）。
  - 根拠なしの「課題の文字数に制限はありますか」「参考文献の書き方に指定はありますか」は判定は正しかったが、答えに「提出先は学習ポータル…」など無関係な FAQ の内容を混ぜ、必須語句「確認」を欠いた。
- 考察：
  - ベースラインの結果は、講師の提示値（`reference/result.json`：format 1.0、content 0.905）と一致した。
  - エポックを半分にすると学習時間は約半分になり、形式遵守率は同じ 1.0 に届いた。一方、内容正解率は 1 問低下し、loss も高いままだった。今回の 14 件では、形式を覚えるのに 10 エポックで足りたが、内容の判断を安定させるには 20 エポックが効いたと読める。
  - 1 回の実行差なので、確かな結論ではない。GPU の学習は完全には再現しない（同じ設定でも結果が揺れる）。
- ファインチューニングが向く場面・向かない場面についての考察：
  - 向く：回答の形式や言い回しを揃えたい（JSON などの出力形式、定型の文面）。数分の学習で形式遵守率が 0.1 → 1.0 に変わった。
  - 向かない：知らない事実を覚えさせて、知らないことへの判断を任せたい場合。今回のモデルは、FAQ に無い締切に FAQ の日付を断定した。事実は学習より検索（RAG や用語集の検索）で渡し、根拠の有無は別に確かめるほうが確実。

- 講師のラベルとの比較（`app.judge --compare`）：根拠・範囲・ヒント・回の表示は 10/10 で一致。分かりやすさは 7/10 で、#01・#02・#07 が講師と違う（自分は不合格、講師は合格）。「迷った」は #05 のみ（講師は #04・#07 にも迷ったを付けている）。
- 基準別の一致率（直す前、LLM の判定と自分のラベルの比較）：根拠 8/9、範囲 10/10、ヒント 10/10、分かりやすさ 7/10、回の表示（コード）10/10。総合 9/9（coverage 90%）
- LLM が要確認とした件数（直す前）：1 件（#05 根拠）
- 直した基準と、書き足した方針：根拠。「用語集にない語について、『用語集にはない』と伝えたうえで一般的に説明するのは、断定ではない（pass）」を追加し、「まだ決めていないこと」の論点を消した（演習の例に沿った方針）。
- 基準別の一致率と要確認の件数（直した後、`judge_result_step3.json`）：根拠 9/10、範囲・ヒント・回の表示 10/10、分かりやすさ 7/10。要確認 0 件（#05 は合格と判定）。総合 10/10（coverage 100%）。不一致は 4 件（#01・#02・#07 の分かりやすさ、#08 の根拠）で、直す前と同じ。
- LLM の判定と自分のラベルで判定が違った項目と、LLM の判断理由：
  - 分かりやすさ：#01・#02・#07 は、LLM が「簡潔で、繰り返しや無関係な説明がない」と判断して合格にした。自分は不合格にした。
  - 根拠：#08 は、LLM が「用語集の全文を出力しており、期待するふるまいに反する」と判断して不合格にした。自分は合格にした。
  - 4 件の理由（LLM の判断）の全文は、STEP 3 後の `lectures/04/judge_result_step3.json` にある。
- 気づき・疑問：
  - 分かりやすさが、LLM と自分の判定で最もずれた（7/10）。「簡潔」や「繰り返し」の判断は人によって変わるため、基準の文言をさらに具体的にしないと、採点器の一致率を信じにくい。
  - #08 では、LLM は用語集の全文を出したことを「期待するふるまいに反する」として根拠を不合格にした。自分は根拠を合格にした。根拠の基準に、ふるまいまで含めるかを決める必要があると感じた。
  - STEP 3 前は「迷った」「要確認」が #05 に集中していた。根拠の基準に方針を追加して再採点すると、#05 は pass となり要確認は 0 件になった。
  - 両モデルで不一致は各 1 件だったが、該当ケースは異なった（ベースライン #06、変更版 #08）。今回の 10 件だけでは、変更版が優れているとは判断できない。
  - 疑問：#01・#02・#07 の分かりやすさは、「読みやすさだけで見る」という基準に照らして、どこまで不合格にしてよいか。
  - 疑問：#07 のように講座外の質問で「第N回」が無い場合、回の表示は不合格にすべきか。この扱いは、基準のどこで決めるべきか。
  - 疑問：LLM の採点を使うなら、どの基準を LLM に任せ、どの基準をコードや人が見るべきか。

## 宿題

- 取り組んだレベル：基礎
- やったこと：
  - STEP 3 前に、同じ 10 件を採点基準を変えずに2モデルで採点した。ベースラインは既定の `gemini-3.5-flash-lite`、変更版は `gemini-3.5-flash`（`temperature=0`）。この比較の後、演習の STEP 3 で採点基準を更新した。
  - 結果は `lectures/04/judge_result_base.json` と `lectures/04/judge_result_model.json` に保存した。
- 結果：

| 項目 | ベースライン（`gemini-3.5-flash-lite`） | 変更版（`gemini-3.5-flash`） |
|---|---|---|
| 根拠（一致率） | 9/10 | 8/9（要確認 1） |
| 範囲 | 10/10 | 10/10 |
| ヒント | 10/10 | 10/10 |
| 分かりやすさ | 10/10 | 10/10 |
| 回の表示（コード） | 10/10 | 10/10 |
| 総合の一致率 | 10/10（coverage 100%） | 9/9（coverage 90%） |
| 要確認の件数 | 0 | 1（#05 根拠） |
| 不一致 | 1 件（#06 根拠、過検出） | 1 件（#08 根拠、過検出） |

  - 変更版で要確認になったのは #05（用語集にない語に「用語集にはない」と伝えたうえで一般的な説明をした回答）。「まだ決めていないこと」の論点に当たるため、LLM が判定を避けた。
  - 両方の不一致は「根拠」の過検出。#06 は用語集にない事柄の断定と判断され、#08 は参照に用語集エントリが無いのに定義を出したと判断された。
- 気づき・疑問：
  - モデル比較時の変更版では #05 が要確認だった。STEP 3 後の再採点（`gemini-3.5-flash-lite`）では #05 が pass となり、要確認は 0 件になった。方針の追加で、この論点が自動判定されたことを確認できた。変更版モデルでは STEP 3 後の再採点をしていない。
  - 同じ「根拠」の基準でも、モデルによって「用語集にない内容を書いた」ことの扱いが違った（#06、#08）。どちらの判定が正しいかは、基準の文言で決めるべき。
